Let the game run the voice chat. Beta

A small Windows app reads your Among Us lobby, and dea mutes and unmutes the voice channel for you.

Players link to their Discord names automatically. You can pause or switch back to manual at any time, and if the connection drops dea steps back to manual and asks before resuming. Automatic mode is in private beta, for Windows only.

See the commands

What dea does each phaseAUTO
  • LobbyEveryone can talk.
  • TasksEveryone is muted.
  • MeetingAlive players talk. Dead players stay muted.
  • EndedEveryone can talk again.

Everyone is muted during tasks, so a mute never gives away who died.
